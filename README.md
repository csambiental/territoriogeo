# Território Rural de Londrina

Mapa interativo do município de Londrina (PR) — CS Consultoria Ambiental.

- `data/fazendas.json`: configuração do mapa (camadas, painel, imóveis)
- `data/bacias/`: bacias, microbacias e rios (ANA/SNIRH), atualizados pela rotina `tools/` via GitHub Actions
- Imóveis rurais: base pública do CAR (SICAR) — a incluir
